Image Cleaner Pro is a comprehensive solution to manage and clean unused images in your WordPress site.

== Features ==
* Advanced image statistics.
* Automatic daily cleanup.
* Image recovery options.
* User-friendly interface.
* Multilingual support (English, Spanish).

== Installation ==
1. Upload the plugin files to the `/wp-content/plugins/image-cleaner` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Access the settings under `Tools > Image Cleaner`.

== Frequently Asked Questions ==
= How do I recover deleted images? =
Visit the 'Recovery' tab in the plugin interface to restore previously deleted images.
